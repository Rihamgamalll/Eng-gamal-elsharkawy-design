# موقع المهندس جمال الشرقاوي

نسخة مطوّرة من الموقع بواجهة عربية أساسية ودعم كامل للإنجليزية، مع استخدام صور المشاريع الموجودة داخل `public` وحركات GSAP متجاوبة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## أهم التعديلات

- العربية هي اللغة الافتراضية، مع زر تبديل مباشر إلى الإنجليزية.
- صورة `Hero.jpg` مستخدمة كواجهة رئيسية مع Parallax وGSAP intro.
- D7 وD8 موضوعتان داخل نفس مجموعة المشروع، وكذلك D12 وD13.
- D16 وD17 مستخدمتان في مقارنة Before / After تفاعلية.
- تم استبعاد D24 من المعرض لأنها نسخة مطابقة تقريبًا لـ D9، لتجنب التكرار البصري.
- إضافة اسم **المهندس جمال الشرقاوي** في الهوية والمحتوى.
- إضافة واتساب، الاتصال المباشر، ورابط فيسبوك في التواصل والفوتر.
- تحسينات Responsive واحترام `prefers-reduced-motion` للحركة.

## تعديل البيانات لاحقًا

- النصوص العربية والإنجليزية: `lib/language-context.tsx`
- رقم الهاتف وواتساب: مكونات `Contact`, `SiteHeader`, `SiteFooter`, `FloatingContact`
- رابط فيسبوك: `components/sections/Contact.tsx` و `components/layout/SiteFooter.tsx`
- الصور: مجلد `public`
